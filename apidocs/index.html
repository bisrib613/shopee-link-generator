Shopee Affiliate Link Generator API

Use this API to turn a Shopee product link into a Shopee affiliate link. The API is public and does not require an API key or login.

1. API Endpoint

Endpoint
https://shopee-affiliate-link-generator.netlify.app/api
Method: POST
Easy way to remember: send a POST request to the Endpoint above, then put your parameters in the request body as JSON.

2. Parameters

Parameter Required? Default What it does
url Yes — Your Shopee product URL or s.shopee.co.id short link.
affiliate_id No 11304530178 Your Shopee Affiliate ID. Leave it out or send an empty value to use the default.
sub_id No kuntyy-social Optional tracking label so you can identify where a link came from.

3. Simplest Example

You only need to send url. The API will use the default Affiliate ID and default Sub ID automatically. 

curl -X POST "https://shopee-affiliate-link-generator.netlify.app/api" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://shopee.co.id/example-product"
  }'

4. Example with Custom Affiliate ID

curl -X POST "https://shopee-affiliate-link-generator.netlify.app/api" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://shopee.co.id/example-product",
    "affiliate_id": "123456789"
  }'

5. Example with Custom Sub ID

curl -X POST "https://shopee-affiliate-link-generator.netlify.app/api" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://shopee.co.id/example-product",
    "sub_id": "my-campaign"
  }'

6. JavaScript Example

const response = await fetch(
  "https://shopee-affiliate-link-generator.netlify.app/api",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      url: "https://shopee.co.id/example-product"
    })
  }
);

const data = await response.json();
console.log(data.affiliateLink);

7. Response

The API returns JSON when the request succeeds:

{
  "success": true,
  "affiliateLink": "https://s.shopee.co.id/an_redir?...",
  "originLink": "https://shopee.co.id/example-product",
  "affiliateId": "11304530178",
  "subId": "kuntyy-social"
}

8. What happens to the URL?

For a normal Shopee product URL, the API cleans the URL before putting it into origin_link. Query parameters are removed, matching the original generator behavior.

For a Shopee short link such as s.shopee.co.id/xxxxx, the API first resolves the short link, then cleans the resulting product URL and generates the affiliate link.

9. Content-Type

The recommended format is JSON: application/json.

For compatibility, the API also accepts application/x-www-form-urlencoded.

10. Common Errors

Error Meaning
Missing required parameter: url You did not send the url parameter.
Invalid URL The value you sent is not a valid URL.
Only Shopee Indonesia URLs are supported The URL is not a supported Shopee Indonesia address.
